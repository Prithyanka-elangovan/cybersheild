# CyberSheild - Linux Security & Network Troubleshooting Lab
## Project Overview
CyberSheild is a hands-on cybersecurity lab that simulates the work of a Junior Security Analyst investingating a linux-based internal web server.
The project combines Linux administration, networking, web security, troubleshooting, log analysis, vulnerability investigation,Python automation and security reporting.
## Role
Junior Cybersecurity/SOC Security Analyst
## Objective
Investigate Linux system activity,network behavior,web activity,security logs to identify suspicious events,troubleshoot issues,investigate potential vulnerabilities and document security findings.

## Key Finding
IP address '192.168.0.101' generated 70 '401 Unauthorized' responses during repeated requests to factory machine-ststus APIs.
Further Investigation showed re-authenticaion followed by '200 Success' respones.
THe activity was assessed as an authentication/session issue,with no confirmed malicious activity
